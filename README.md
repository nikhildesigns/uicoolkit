# UICoolKit

Thoughtfully animated, production-ready React components for the moments that make a product feel finished.

[Website](https://uicoolkit.com) · [Contributing](./CONTRIBUTING.md) · [License](./LICENSE)

> UICoolKit is in early development. The public component catalog and installation endpoints have not launched yet.

## What UICoolKit Is

UICoolKit is a source-delivered React UI library focused on polished product interactions and complete interface states. Components are designed to live in your application so you can inspect, adapt and own the resulting code.

The library is intended to sit between low-level primitives and effect-heavy showcases: useful product UI with thoughtful motion, accessible behavior and realistic states.

## Quality Principles

Every applicable component is expected to provide:

- TypeScript with a focused, documented API.
- Keyboard, focus and semantic accessibility.
- Reduced-motion behavior.
- Responsive layouts and light/dark themes.
- SSR and hydration safety.
- Relevant loading, empty, error, retry, disabled and success states.
- A realistic product-context preview.

## Compatibility

The planned compatibility target is:

- React 18 and 19.
- Next.js and Vite applications.
- Tailwind CSS 4.
- Source installation through a shadcn-compatible registry.

Exact installation commands will be published with the first component release.

## Free and Pro

This repository will contain the approved free component collection under the MIT License. UICoolKit Pro will provide larger patterns and complete product flows through a separately licensed source registry.

No paid component source, private registry implementation or internal project material belongs in this repository.
