# Theming

Use your app's shadcn theme and Tailwind CSS 4 setup. The catalog's visual treatment is not a required customer theme.

## Host tokens and aliases

Keep the host's semantic colors, typography, spacing and utility aliases. Imported source uses the configured cn utility and composable part class names. It does not import website theme wrappers or fixtures.

## Overlays

When a portal leaves an isolated theme subtree, pass the documented container option. Keep that container mounted while content is open. Inspect focus indicators, overlays, contrast and disabled states in light and dark themes.

## Verify your changes

Use real content at phone, tablet and desktop widths, with both ordinary and reduced motion. Source editability does not replace accessibility checks after restyling.
