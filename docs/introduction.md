# UICoolKit

Selected React interactions, expressive elements and product compositions, delivered as editable source you own.

## Open source

Browse the [Library](/components) or the [Design Tools collection](/design-tools). The library uses the MIT license. Install any item without an account.

## How the library is organized

Components are individual pieces; Blocks coordinate them into useful sections. Flows carry state across steps, Pages are complete host-themed screens and Templates are multi-page starting projects. Visuals are expressive assets.

Each item has one Topic. General UI holds reusable generic components; Design Tools describes domain-specific editor capabilities.

## Start with installation

Read the installation guide, then a selected item's usage, API, customization and accessibility notes. To use a coding agent, [copy the project setup prompt](/docs/agents).
