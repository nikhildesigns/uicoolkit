# Customization

The default appearance is a starting point. All Free items deliver readable source and expose styling, composition, state and motion hooks.

## Style and content

Use root/part className, native attributes and ref access. Class overrides merge after defaults. Replace displayed content, row metadata, action labels and state surfaces through each item's documented parts or render functions. Read the item's substantially restyled and custom-content examples.

## Application-owned behavior

The host owns data, authorization, persistence and failure recovery. Return promises from documented callbacks and update controlled state after success. Preserve validation, pending, error and retry surfaces. Multiple configured instances must remain independent.

## Motion

Use the item's motion option to disable optional animation and honor reduced motion. Turning effects off must retain every essential operation. For phones, overlays use bottom sheets.

## Source editing

Edit delivered internals when documented hooks do not cover the request. Recheck keyboard/focus, semantics, themes, supported states and updates afterward. There is no paid customization unlock or required UICoolKit runtime.
